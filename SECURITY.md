# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for a suspected vulnerability.

Include the affected revision, a minimal reproduction, and the impact you
observed. Reports are acknowledged through the same advisory thread.

## Scope

This repository is a proof of concept. It is not an official Subsea Cable
Runtime and is not intended for production use. Reports about the Subsea Cable
language itself belong in
[on-the-ground/subsea_cable_language](https://github.com/on-the-ground/subsea_cable_language).
